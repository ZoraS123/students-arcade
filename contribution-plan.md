# Contribution plan

Issue: #33 Add a greeting-message arcade plugin
Issue URL: https://github.com/AmalChUm/students-arcade/issues/33
Selected difficulty: beginner
Proposed branch: feature/issue-33-greeting-message
Expected files: plugins/greeting_message.py

## My interpretation of the task

Create a new arcade plugin that randomly selects and displays one friendly greeting from a list of at least six greetings.

## Acceptance criteria

- [ ] The new file is placed in plugins/ with a unique descriptive filename.
- [ ] The plugin includes at least six friendly greetings.
- [ ] The module defines AUTHOR, APP_NAME, and run().
- [ ] The module uses only the Python standard library.
- [ ] python main.py discovers and runs the plugin.
- [ ] The output is readable.
- [ ] main.py is not modified.

## Possible risks or questions

- Make sure the plugin is discovered automatically by main.py.
- Make sure no external packages are used.
